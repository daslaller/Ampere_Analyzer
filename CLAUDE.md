## What this is

**Ampere Analyzer** — a single-page tool for electronics engineers and
hobbyists that estimates the **maximum safe continuous current (amps)** of a
power transistor (MOSFET / SiC / GaN / IGBT / BJT) at a given switching
frequency, ambient temperature and cooler. Nothing to do with batteries or
charging. Specs come from 5 presets, manual entry, an uploaded PDF datasheet
(read by Gemini), or an LLM "search".

- **Generated by Firebase Studio** (package name `nextn`, `.idx/`,
  `docs/blueprint.md`; `README.md` is the stock starter text).
- **Stack:** Next.js 15 (App Router, Turbopack), React 18, TypeScript 5.7,
  Tailwind 3.4 + shadcn/ui, Genkit + `@genkit-ai/googleai` (Gemini). npm,
  `package-lock.json` v3. No `engines`/`.nvmrc`; Node 20 implied by
  `.idx/dev.nix`.

## Architecture that spans files

- **One route.** `src/app/page.tsx` (client) renders
  `src/components/app/ampere-analyzer.tsx` (~709 lines) — all state:
  react-hook-form + a zod schema, the dialogs, the History tab (localStorage key
  `simulationHistory`, max 50), and the deep-dive orchestration.
- **Simulation runs in a plain-JS Web Worker** (`public/simulation-worker.js`),
  which TypeScript does **not** check. Loss model: conduction I²·Rds(on)·0.5
  (or I·Vce(sat)·0.5), switching 0.5·Vmax·I·(tr+tf)·f, junction temp
  Tamb + P·(RthJC + cooler Rth); limits checked Thermal → Power → Cooling →
  Current; modes `ftf`/`temp`/`budget`; iterative or binary search.
- **AI is Genkit**, default model `googleai/gemini-2.0-flash`
  (`src/ai/genkit.ts`). Six flows in `src/ai/flows/`, reached **only** through
  Server Actions in `src/app/actions.ts` — no API routes, no middleware. The
  finder/best-effort prompts say *"Simulate a Web Search"* with **no grounding
  tool wired**, so results can be invented.
- **Static data** in `src/lib/constants.ts` (24 coolers, 5 transistors, 7
  types). No database, no auth; the `firebase` dependency is **unused**.
- **UI:** shadcn/ui (`components.json`: default/neutral/CSS-vars/lucide), Tailwind
  3.4, Recharts, framer-motion; theme in `src/app/globals.css`.

## ⚠️ Known bugs on `master` (recorded, not fixed)

- **Two AI features are dead:** `getAiCalculationsAction` /
  `getAiSuggestionsAction` are imported (`ampere-analyzer.tsx:10`) but never
  called, so the "AI-Calculated Safe Limits" and "Optimization Advisor" cards
  never render — and the "Start AI Deep Dive" button lives *inside* the advisor
  card (`results-display.tsx:315`), so it is unreachable.
- **Binary-search returns 0 A for small transistors:**
  `maxIterations = Math.log2(high-low)*15` goes negative when Imax < ~0.67 A
  (`simulation-worker.js:179`) — hits the 2N7000 and BS170 presets.
- The worker never emits `status:'failure'`, so the failure alert never shows;
  the `industrial-passive` cooler is in no dropdown group; `isMosfetType` is
  copied in three files; `firebase`, `@genkit-ai/next` and `patch-package` are
  unused deps. `docs/blueprint.md`'s colours no longer match `globals.css`.
